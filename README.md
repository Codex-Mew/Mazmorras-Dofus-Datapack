DOFUS Populus – Dungeon Fixes (SQL)

Este proyecto reúne una colección de parches SQL orientados a solucionar problemas comunes en las mazmorras del datapack Populus, tales como:

- Spawns incorrectos de monstruos
- Configuración incorrecta de grupos de mobs

El objetivo es proporcionar scripts simples de aplicar para mantener las mazmorras funcionales y estables dentro del servidor, No son los mejores y pueden existir mejores metodos mejores.

Para instalar estos parches, solo debes de descargar los archivos SQL, ejecutalos en tu base de datos la cual debe de ser "world".

Este repositorio se distribuye con fines educativos.
